# 🎲 Gambling CLI Game (Python 3)

A simple, interactive command-line gambling and banking game written in Python 3. Built as my first 70+ line Python project on mobile using **Acode Pro**.

---

## ✨ Features (v2)

* **Starting Wallet:** Begin the game with **$100**.
* **Betting System:** Place bets against a 50/50 random chance (`random.randint`) to double your bet or lose it.
* **Bank System:**
  * **Deposit** money from your wallet to keep it safe from risky bets.
  * **Withdraw** saved money back into your wallet anytime.
  * **Check Bank Balance** separately from your wallet balance.
* **Input Validation:** Prevents betting, depositing, or withdrawing `$0`, negative numbers, or more money than you currently have.

---
